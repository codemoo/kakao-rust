# 지원 범위와 제한

현재 제공하는 기능과 미지원 범위입니다. 실제 검증 결과는 [TESTING.md](TESTING.md), 명령은 [USAGE.md](USAGE.md), API 사용법은 [API.md](API.md)를 참고하세요.

| 기능 | 지원 범위 | 제한 |
| --- | --- | --- |
| 로그인 | 비밀번호 입력, 휴대전화 기기 승인, 세션 저장 | 추가 이메일 인증·약관 동의 등 일부 분기 미지원. QR 로그인은 실제 계정 검증 미완료 |
| 연결 유지 | 저장된 로그인 상태 사용, 연결 복구 | 로그인 상태가 유효하지 않으면 사용자 조치 필요 |
| 과거 대화 복원 | 톡서랍 대화 복원과 중단 후 재개 | 녹음이 있는 계정의 후처리 미지원. 서버 안내 건수와 반환 건수가 다를 수 있음 |
| 새 메시지 | 상시 수신·저장, 재시작 후 재처리 | 검색 대상은 텍스트·답장 중심. 미지원 메시지 유형은 원본 보존 |
| 수정·삭제 | 수신 알림과 누락 재조회에 반영, 검색 인덱스 갱신 | 수정 본문이 없으면 재조회. 서버에서 제공하지 않는 기록은 복구 불가 |
| 누락 복구 | 방별 수집 위치와 이전 메시지 연결 검사, 미완료 구간 재조회 | 커뮤니티 전용 보관소 자동 복구 미지원. 대기 구간 0건이 전체 기록의 완전성을 뜻하지 않음 |
| 친구 | 전체·증분 목록, 건수 불일치 보정, 별명·프로필 이름 | 현재 관계와 과거 발신자 신원을 분리하여 보존 |
| 연락처 이름 | 기존 백업 읽기, 완성된 목록 교체, 전화번호 연결 | 연락처 업로드·주소록 수정 없음. 모호한 번호 연결은 이름 대체 안 함. 모든 국가의 번호 형식 미지원 |
| 참여자 | 일반 채팅 명단과 일반·오픈채팅 방별 프로필, 변경 시 갱신 | 오픈채팅 명단의 자동 열거와 비밀채팅 전체 명단 미지원. 빈 응답으로 기존 명단을 지우지 않음. `coverage.complete` 확인 필요 |
| 방 정보 | 공유 제목, 활성 상태, 수신한 읽음 위치 | 읽음 위치와 수집 위치는 분리. 방 열기·읽음 요청을 전송하지 않음 |
| 차단 목록 | 사용자·채널별 목록, 프로필 차단 상태, 별도 이름 조회 | 일부 관계·추천 상태의 반영 미지원 |
| 자동 갱신 | 친구·연락처·설정·방 정보 갱신, 실패 시 재시도 | 일부 기능별 알림 처리와 전체 설정 동기화는 미완료 |
| 이미지·파일 | 메타데이터 수집, 인증된 API 요청 시 내용 다운로드 | 512MiB·동시 2개·시간 제한. 비밀채팅 미디어와 일부 주소 재발급 미지원. 보관 만료 자료는 다운로드 실패 가능 |
| 조회 API | 메시지·검색·친구·차단·참여자·누락·첨부파일·SSE | 계정·권한·방 제한 적용. 페이지 조회는 고정 snapshot이 아님 |
| 플랫폼 | macOS·Linux·Windows(WSL2) | Windows 네이티브 실행 미지원. WSL2 직접 검증은 미완료 |
| Tailscale | loopback API를 비공개 HTTPS로 제공 | API 토큰 필수. 별도 허용·비허용 기기의 실제 접근 검증 남음 |
| 메시지 발송 | 일반 1:1·그룹 채팅의 짧은 텍스트, 쓰기 권한·방 제한, 중복 요청 처리·결과 조회 | UTF-16 3999단위 이하. 이미지·파일·답장·오픈채팅·비밀채팅·키워드 효과 미지원. 불확실한 결과는 `unknown`으로 보존 |

## 운영 시 확인할 사항

- 전체 과거 대화의 보존 여부는 서버에서 제공하는 기록에 따라 달라집니다.
- 참여자 명단과 수집 상태는 API의 확인 상태를 함께 확인하세요.
- 메시지 조회·발송은 방 열기나 읽음 표시를 수행하지 않습니다.
- 메시지 발송의 접수와 완료는 다릅니다. `sent` 상태를 확인하고, 결과가 불확실한 요청은 새 요청으로 반복하지 마세요.
- 데이터 디렉터리는 호스트의 접근 권한과 백업 정책으로 보호하세요. 자세한 절차는 [설치와 운영](USAGE.md)을 참고하세요.
