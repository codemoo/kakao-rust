# 검증 결과와 재현 방법

검증일: 2026-11-13. 합성 데이터 검사와 실제 계정에서 확인한 동작을 구분합니다.

## 자동 검사

```sh
./scripts/check.sh
```

macOS arm64 / Rust 1.88.0에서 테스트 166개, rustfmt, Clippy `-D warnings`를 통과했습니다. GitHub Actions는 Ubuntu·macOS와 Rust 1.88·stable 조합으로 같은 검사를 실행합니다. 실행 결과는 [Actions](https://github.com/codemoo/kakao-rust/actions/workflows/ci.yml)에서 확인할 수 있습니다.

테스트는 합성 데이터와 로컬 HTTP fixture를 사용합니다. 실제 계정 비밀번호·토큰·개인 대화를 사용하지 않습니다. 임시 디렉터리는 OS의 임시 경로에 `0700` 권한으로 생성합니다.

## 실제 계정에서 확인한 범위

macOS에서 저장된 세션을 사용해 다음 동작을 확인했습니다. 메시지 내용·이름·전화번호·인증정보는 공개 검증 자료에 포함하지 않습니다.

- 비밀번호 로그인과 휴대전화 승인, 녹음 0건 계정의 톡서랍 대화 복원.
- 친구 목록의 서버·로컬 건수 일치와 갱신 위치 저장. 연락처는 백업이 없는 분기 확인.
- 새 메시지 수신·저장, 필터 조회·단건 조회·SSE 알림, 같은 세션으로 재시작 후 연결 복구.
- 일반 그룹 채팅에 API로 텍스트 1건 전송. 서버 성공 응답과 조회 API의 본문·본인 발신자 일치, 전송 시도 1회·정규 메시지 1건, 임시 쓰기 토큰 회수 확인.
- 일반 채팅 참여자 명단·이름과 `coverage.complete=true`. 오픈채팅 프로필 출처 조회는 확인했으나 전체 명단 완료는 미확인.
- 사용자·채널 차단 목록과 별도 이름 저장, 차단 목록 API 조회.
- 인증된 API 요청을 통한 최근 이미지와 복원 이미지 다운로드. 만료 자료의 실패 응답도 확인.
- 유효 API 토큰의 HTTP200, 무인증·회수 토큰의 HTTP401. Tailscale HTTPS에서는 유효 토큰200·무인증401 확인.
- DB 백업과 무결성 검사 후 스키마 14 이전, 기존 세션·기록 유지, 친구·연락처·설정 유지 작업의 실패 0 상태.
- 수집기 프로세스의 네트워크 접근을 차단해 재시도를 관찰한 후, 정상 서비스로 재시작하여 연결 복구. 동일 프로세스에서 차단을 해제한 시험과는 구분.

확인 당시 누락 재조회 대기 방은 0개였습니다. 이 수치는 과거 전체 기록의 완전성을 보증하지 않습니다. 72시간 상태 관찰은 시작했으나 완료 결과는 아직 확정하지 않았습니다.

## 미검증·미지원 범위

- 실제 발송 중 연결 단절·재시도와 다른 메시지 유형 발송. 연결 오류·응답 누락·재시작 처리는 합성 검증만 완료.
- 장기간 사용 후 재로그인이 필요한 상황, 자연 발생한 친구 수 불일치 복구.
- 이름이 있는 실제 연락처 백업과 모든 국가의 전화번호 매칭.
- QR 로그인의 실제 계정 호환성, 오픈채팅 전체 명단 완료, 비밀채팅과 전체 명단 처리.
- 녹음이 있는 계정의 복원 후처리, 모든 첨부파일 형식, 커뮤니티 보관소 누락 복구.
- 모든 기능별 알림·관계·설정 처리와 전체 동기화 완료.
- 수일 이상 무중단 운영 완료, 별도 Tailscale 허용·비허용 기기의 접근 제어. 현재 HTTPS 검증은 설치한 노드의 전송 경로를 사용했습니다.
- WSL2 직접 실행 검증. Linux 실계정 검증은 현재 범위에서 제외합니다.

Linux에서는 합성 데이터로 빌드·테스트·API를 검사했으며, 실제 세션을 복제하거나 여러 호스트에서 동시에 실행하지 않았습니다. 기능별 지원 경계는 [지원 범위](PARITY.md)를 참고하세요.
